## 🔓 Projetos de Demonstração (Criados via Vibe Coding / IA)
*Repositórios públicos demonstrando sistemas funcionais concebidos, gerados e integrados por meio de desenvolvimento assistido por Inteligência Artificial, com foco na regra de negócio e no funcionamento prático.*

### [Automação de Backup MySQL](https://github.com/Katiallz/Backup-Banco-de-dados)
Aplicação construída via IA utilizando **Node.js e MySQL** para gerar e compactar backups periódicos de bancos de dados automaticamente. Conta com integração via webhooks (Discord), variáveis de ambiente e tratamento de erros.

### [Painel Mecânico para FiveM](https://github.com/Katiallz/Painel-Mecanico-Fivem)
Sistema completo para gerenciamento corporativo de oficinas. Permite controle de membros, cargos, permissões, histórico de atendimentos e transações financeiras. Estruturado via engenharia de prompt e validação prática com **Lua, JavaScript, HTML, CSS e MySQL**.

### [Loja de Mecânica com Svelte](https://github.com/Katiallz/Fivem-Mechanicshop)
Interface moderna, rápida e reativa para loja integrada ao painel mecânico, com comunicação cliente-servidor construída em fluxo de desenvolvimento assistido por IA utilizando **Svelte, TypeScript, Vite, JavaScript e Lua**.

### [Sistema Interativo de Venda (NPCs)](https://github.com/Katiallz/fivem-drugs-script)
Script de interações in-game desenvolvido com auxílio de IA, onde jogadores interagem com NPCs pelo mapa, com diálogo dinâmico em 3D, probabilidades de reação e sistema anti-spam.
